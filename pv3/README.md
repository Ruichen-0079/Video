# 《万花行记》概念 PV · 第三版「逝水」

约 33 秒，一个镜头，一条河。

成片：`release/wanhua_pv3_1080p.mp4`（1920×1080，30 fps）

画面里没有人，也没有人物的名字和说明字幕，只有夜里的一段河面：水是真的在动的（波动方程逐帧推进），光照到河床上聚成焦散，花瓣与书页随水流漂走。所有画面都是代码在浏览器里逐帧算出来的，配乐也是逐个采样合成的，没有使用任何素材、图片或生成式模型。

---

## 为什么是水

设定的序里，有三句话我反复读：

> 中华文明浩荡如山海的历史，在《永乐大典》的火焰中随风飘去……古书如溪流向京都汇聚。
>
> 历史从过去涌来，停滞在这片宽敞却狭小的不可思议的地方……过去的已不再来了。
>
> "逝者如斯夫，陛下。" / "真是他妈的，逝者如斯夫。"

序的开头和结尾都是「逝者如斯夫」，原话出自孔子在河边说的「逝者如斯夫，不舍昼夜」。所以这一版只拍一样东西：**一条河**。镜头从头到尾俯视着同一段夜里的河面，时间在河上流过：先是灯与雨，然后是火，接着是月、花、信与城。

这一版刻意避开前两版的问题：

- 没有用来装饰的粒子和线条。画面里每一个会动的东西，都是落在水上的一样具体的东西，比如雨、书页、剑、水滴、花瓣、信。它们在水面上激起的波，都是物理模拟算出来的。
- 没有剪影和人像。人物只以「留在水上的痕迹」出现：一滴一滴落下的水、一把沉底的剑、一封信。
- 不堆砌古风符号。没有山河、武者、书卷的全景，只有一个对象（河面），配上对得上原作的几件具体物件。

## 结构

| 时间 | 段落 | 河上发生的事 | 对应 |
|---|---|---|---|
| 0–5 | 灯 | 黑暗里一盏暖灯的倒影，第一滴水落下。雨渐密，每一滴都是一个环，环与环相互穿过 | 序：「为乾隆提着灯」。雨是众生 |
| 5–9 | 火 | 天色被映红，燃烧的书页从空中飘落，一页页落水，「嗤」的一声熄灭，成为焦黑的残片顺流漂走。书页是朱丝栏写本 | 序：「在《永乐大典》的火焰中随风飘去」「古书如溪流向京都汇聚」 |
| 9.0 | 斩 | 一道刀锋横过整条河，一线白浪，一缕朱砂在水里散开。雨在这一刻停了，火也灭了 | 老人的最后一剑，一个王朝的终结 |
| 9.5–12 | 放手 | 一把剑落进水里，摇摆着沉到河底 | 武道的「放手」 |
| 12–18 | 守 | 镜头悬在正上方。月在天顶，倒影在河心；每隔一拍半，一滴水正好落进月亮，月碎成一圈圈的环，又慢慢圆回来。河底的剑被泥沙一点点盖住 | 「守」；不老的人独自度过的漫长时间，一滴一滴像漏刻 |
| 18.5–23 | 遇 | 河的另一处亮起一盏暖灯，第二处滴水与第一处错开半拍。两组环相遇、相互干涉。花瓣从空中落下，几簇几簇地顺流漂过两盏灯之间，被每一圈波轻轻推开，又彼此聚拢 | 相遇；万花洲；落花流水 |
| 23.3 | 别 | 她那一处的滴水停了，灯灭了。他的还在继续 | 不写她的结局，只写她离开 |
| 23–28 | 信 | 一封信从空中飘下，落在水面上。纸慢慢湿透、变暗，墨从纸上洇进水里，顺流拖成几道；然后纸沉下去，看不见了 | 序：「她留下的信纸」 |
| 25–31 | 城 | 起风了，镜头抬起，远处对岸城市的灯在水里被拉成一道道光柱，车灯沿岸线流过。风停下来，水重新成为镜子，倒影里浮出四个字：万花行记 | 序：「车灯的暖光划开城市的冷淡……从街的这边驶来，那一边逝去」 |

## 几处具体的意思

- **雨与滴水**：雨是许多人，落得又密又乱，在斩的那一刻同时停下。之后的水滴只有一处，固定的间隔，像漏刻（古代的水钟）。不老的人用这种方式度过时间。
- **两盏灯**：月是冷的、恒常的，属于他；她是一盏暖灯。两处倒影各自被各自的水滴打碎，两组波纹在中间相遇。
- **书页与信**：书页是被记载的历史（印着朱丝栏和字），它们在火里落下；信是私人的记忆，无声地沉没。设定里说，「历史事实与私人记忆，可以有各自不同的表达方式」。
- **剑**：被放下的剑躺在河底，泥沙在之后的二十秒里慢慢把它盖住。
- **题字**：书名不在画面上方，而在水的倒影里。只有当水完全平静的时候，才读得出来。

## 尊重原作的几条自我约束

- 没有任何人名、台词或说明字幕。画面里唯一的文字是书名。
- 信里写了什么，原作没有说。所以信纸上只有程序画出的笔迹（横竖撇捺点），**不构成任何字**，远看像字，近看读不出。
- 书页用的是朱丝栏写本的样子，因为序里提到的是《永乐大典》。设定中关于大典焚毁时间的待核对项，画面不涉及。
- 她离开时，画面只让她那一处的滴水停下、灯熄灭，没有表现死亡，也没有表现重逢。她的结局在设定里是【未定】的。
- 「老人的最后一剑衔接推翻王朝」来自作者二改意见。这里只有一道刀锋、雨停与火灭，没有画出人。

## 技术

```
pv3/
  index.html          渲染页面
  src/main.js         时间线、事件、镜头；按帧推进模拟；window.PV.renderFrame(t)
  src/shaders.js      全部着色器
  audio/score.py      配乐合成（numpy）：水滴、泛音、刀鸣、入水、大鼓、锣、箫、琴、垫音、卷积混响
  tools/events.py     事件表 assets/events.json（画面与配乐共用）
  tools/fonts.py      字体子集
  render/render.mjs   无头 Chromium 逐帧渲染 → ffmpeg
```

- **水面**：1024² 的高度场（覆盖 6 米见方），按二维波动方程每帧推进 4 个子步，边缘有吸收层。雨滴、水滴、剑、书页、信、花瓣落水时，都往高度场里注入一个波包；刀锋扫过时，沿扫过的线段施加一个速度冲量。
- **风吹出的涟漪**：20 道不同方向和波长（3.5–30 厘米）的水波，按毛细-重力波的色散关系各自传播，再乘上一块块缓慢漂移的「阵风」遮罩，所以河面上有的地方起皱，有的地方还是镜子。
- **焦散**：分两部分计算。水滴激起的大波，用网格折射投影求出光线落到河床上的疏密。细碎的涟漪，在每个像素上用折射映射的雅可比行列式解析地求出焦散，所以河床上的光网足够锐利，不会糊成一片。
- **着色**：每个像素沿视线落到水面，按 Fresnel 混合反射与折射。反射的是一个解析的夜空（灯、火光、月和月面、她的灯、城市灯火、车流、题字）；折射穿过水体（按路径长度吸收与散射），落到河床、剑或信纸上。墨（朱砂与信上的墨）在另一张贴图里随水流做半拉格朗日平流并慢慢扩散，在水中按吸收着色。
- **漂浮物**：花瓣（五种瓣形，外加偶尔一整朵）、书页和空中的信，都是实例化的四边形，可以在空中翻飞，也可以浮在水面上随波起伏。花瓣落水后的漂流在 JS 里逐帧积分：水流速度场，加上每次滴水激起的环经过时向外的推力，再加上漂浮物之间的毛细吸引（所以花瓣会聚成簇）。书页的燃烧边缘、焦黑、余烬、落水后的熄灭与浸湿，都在片元着色器里按「离边缘的距离 + 噪声」的场来计算。
- **镜头**：在「守」的一段，镜头悬在水滴的正上方，月在天顶，所以月的倒影、水面的环、河床上焦散的环正好同心。镜头位置由几何关系反解得到。
- **画面与声音共用 `events.json`**：每一滴雨、每一页书、每一次滴水、信落水的时刻，在画面和配乐里是同一个时间。
- 模拟是有状态的，所以渲染必须按顺序逐帧进行（单进程）。1080p 下每帧约 2–3 秒（SwiftShader 软件渲染）。

## 运行

```bash
cd pv3
npm install                          # 只需要 playwright-core
python3 tools/events.py              # → assets/events.json
python3 audio/score.py               # → assets/score.wav
node render/render.mjs --stills 7.5,14,21,30 --w 960 --h 540      # 抽帧检查
node render/render.mjs --w 960 --h 540 --out out/preview.mp4       # 预览
node render/render.mjs --w 1920 --h 1080 --crf 18 --out out/pv3.mp4  # 成片
```

需要 Chromium（`CHROME` 环境变量可指定路径）、ffmpeg、Python 3 + numpy + scipy。字体子集已经提交在 `assets/fonts/` 中。

## 制作过程中推翻过的东西

- 第一稿的河床是亮的卵石滩，像游泳池。后来改成很暗的细沙与淤泥，大部分画面是黑色的镜面，只有被光照到的地方才看得见河底。
- 第一稿的细碎水面用的是值噪声的梯度，焦散像一张拉长的渔网。后来改成符合色散关系的多向水波，并按像素解析求焦散。
- 刀锋第一稿是一道发光的线，像光剑。后来改成一线白浪加一缕在水里散开的朱砂。
- 花第一稿是整朵贴纸一样的小花，带黄色花心。后来改成单片的花瓣，有瓣根的深色、脉纹和瓣缘的透光，并让它们随水流聚散。
- 信第一稿是一张白色的便签，字是序里的原文。后来考虑到信的内容原作没有写，改成读不出的笔迹，纸也改成会湿透、会沉没的。
- 书名第一稿在倒影里左右颠倒了。
- 「守」一段第一稿是斜俯视：月的倒影确实落在水滴上，但河床上的焦散环因为光线斜射而偏开了一段距离，看上去像水滴没有打中月亮。后来把月放到天顶，镜头悬在正上方。
- 燃烧的书页第一稿落水后还亮着，像河灯。现在落水后不到半秒就熄灭，吸水变暗。
