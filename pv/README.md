# 《万花行记》PV · 制作说明

一支约 2 分 27 秒的程序化 PV。画面中的每一帧都由代码在浏览器里画出（Canvas 2D + WebGL），再由无头 Chromium 逐帧渲染，交给 ffmpeg 封装。配乐用 numpy 逐个采样合成，没有使用任何采样、素材、图片或 AI 生成的画面，人物剪影也是用代码搭出来的。

成片：`release/wanhua_pv_1080p.mp4`（1920×1080，30 fps）

---

## 我对这部作品的理解

设定里有一句话，我几乎把它当成了美术总纲：

> 历史事实与私人记忆，可以有各自不同的表达方式。

于是全片只用两种「物质」：

- **墨**：落在纸上，会吸收光。它用来表现被记载的历史，比如长卷、朝代印、斩下的朱砂一笔。
- **光**：落在夜里，只做加法。它用来表现活过的时间，比如灯、海、剑的光迹、花海、车流。

两种画面之间的转场，也都取自原作的意象：

- 火：夜被烧穿，露出纸（序中《永乐大典》的火，后来又是宫殿的火）。
- 墨洇开：纸上入夜。
- 光：从黄泉门前的那一点、从重逢的那一点烧穿纸面。

**人物只出现为剪影**，不出现名字、不画脸，也不用二次元立绘。同一个剪影有两种呈现，和两种物质一一对应：

- 纸上是**墨影**：一团人形的墨，边缘被纸吸开。
- 夜里是**逆光剪影**：一块挡住光的暗影，边缘一圈微光。

另外还有一条线贯穿始终：

- 一根始终不断的墨线，是那个不老的人。
- 后来出现的一根石青色的线，是她。她负伤之后，一道朱砂细线就一直跟在旁边。
- 众生是一道道写下又淡去的短笔。

## 二改（根据作者意见）

1. **不出现具体人名**，包括序里的「乾隆」。原来写着名字和称号的地方，都换成用剪影演出的具体事件：少年离乡、断臂、摸头、老人的剑舞衔接人类天子率军推翻王朝、她率军、负伤出逃、诗书、美利坚的军衔。剪影都模糊、带象征性，只给姿态，不给五官。
2. **去掉单独出现的「忘记了想象力」**，换成逃兵独行加侧脸嘴角的一牵。
3. **风格保持统一**：剪影沿用全片的两种物质（纸上墨影、夜里逆光），转场仍然是火、墨、光。时长从 2:40 收到 2:27，配乐按新结构重写，每个重音都对在动作上：斩（10½）、剑舞最后一剑（16）、背上的刀（20¼）、嘴角（23）、万花（26）、重逢（37⅓）、书名（44）。

## 尊重原作的几条自我约束

- 画面里只剩作者序中的原文（「夜深了。」「逝者如斯夫，陛下。」「我看见时间尾随其后……」「真是他妈的，逝者如斯夫。」）和地名「万花洲」。没有替人物编台词。
- 【未定】的内容都留成开放的：黄泉还魂的结果、剑灵的形象、清朝在架空史中的位置。**她的结局尤其如此**：她的线最后只是走出画面，没有被画成熄灭。
- 剪影的服饰与道具（包袱、旗、三角帽、帆船）只是象征，不是对人物外貌的设定。
- 「老人的剑舞衔接推翻王朝」来自作者的二改意见。画面只表现舞剑与覆灭的衔接，没有暗示老人在此时去世。

**关于书名**：设定总览写的是《万花行记》，片中按它使用。如果正式书名是《万花行迹》，改 `src/config.js` 里的一行，再运行一次 `tools/build_assets.py` 和渲染即可。

## 研究参考作品时学到、并刻意没有照搬的东西

参考 MV（world.execute(me) 同人，Claude Code 制作）真正值得学的，不是那些镜头，而是：

1. 给整部作品找一种「原生材料」。它的材料是聊天界面，这里是墨与光、纸与夜。
2. 色彩少而有叙事。这里只用墨、朱砂、石青、月白、灯金和花海的柔色。
3. 文字是被「写」出来的（按笔顺）。
4. 结构首尾相扣：开头是「逝者如斯夫，陛下」，结尾是「真是他妈的，逝者如斯夫」。
5. 确定性的 `renderFrame(t)` 加无头浏览器逐帧渲染，反复抽帧检查。

刻意不做的：不用立绘，不做 UI 隐喻，不做高密度的歌词卡点。

## 技术

```
pv/
  index.html            渲染页面
  src/main.js           window.PV.renderFrame(t)：给定时间，确定地画出一帧
  src/gl.js             WebGL2 合成器（HDR 光缓冲、墨吸收、剪影遮挡层、纸/夜背景、焚/洇/光转场、bloom、ACES、颗粒）
  src/silhouette.js     剪影：二维骨架 + 衣袍/袖/发/随身之物；metaball 式平滑；墨影与逆光两种呈现；单线侧脸；宫殿、民居、书案、帆船
  src/camera.js         透视相机与景深
  src/draw.js           三维折线、毛笔线（压力、收锋、飞白）、墨晕、调色板
  src/text.js           Canvas 字体排版；按笔顺书写（Make Me a Hanzi 笔画中线）
  src/fx.js             光写字、墨写字、印章
  src/timeline.js       节拍表（与音乐共用 assets/cues.json）和全片调色
  src/scenes/*.js       九个段落
  audio/score.py        配乐合成：琴（加法合成拨弦，带吟猱滑音）、弹拨、箫、弦乐、编钟、大鼓、锣、海浪、火、剑尖拖地声、城市嗡鸣、FFT 卷积混响
  render/render.mjs     并行逐帧渲染 → ffmpeg
  tools/build_assets.py 从源码收集用到的汉字，生成字体子集与笔画数据
  tools/sheet.py        联系表（抽帧检查用）
```

几个要点：

- **光、墨、遮挡三层**：光（加色）和墨（吸收，按 `exp(-吸收率)` 作用在纸上）分开累积；夜里的剪影写进遮挡层，挡住身后的光，光晕再从边缘漫进来，就是逆光的样子。
- **剪影是搭出来的**：骨架给出关节位置，肢体是锥形胶囊，衣袍、袖子、长发是随风摆动的多边形。整体画进遮罩后先模糊再重新阈值化，关节和衣褶融成有机的轮廓，最后按场景转成墨影或逆光。手放在孩子头上、剑尖拖在地上，这类接触都是先对骨架求解出来，再画出来的。
- **一切都是时间的函数**，没有逐帧累积的状态，所以可以把时间轴切成几段并行渲染。剑舞的光迹，是把过去每个时刻的姿势重新算一遍、取出剑尖位置连成的线。
- **画面与音乐共用节拍表**，所有关键动作都按「第几小节第几拍」来写。
- **颗粒加在伽马之后**，暗部不会被放大成噪点，码率约 5 Mbps。

## 运行

```bash
cd pv
npm install                               # 只需要 playwright-core
python3 audio/score.py                    # → assets/score.wav（约 25 秒）
node render/render.mjs --stills 30,84,140 --w 960 --h 540      # 抽帧检查
node render/render.mjs --w 640 --h 360 --out out/preview.mp4   # 快速预览
node render/render.mjs --w 1920 --h 1080 --crf 18 --out out/pv.mp4  # 成片（4 核约 1 小时）
```

需要 Chromium（`CHROME` 环境变量可指定路径）、ffmpeg、Python 3 + numpy + scipy。字体子集与笔画数据已经提交在 `assets/` 中。

## 制作过程中推翻过的东西

- 最初的风格测试是粗而亮的发光线，像屏保。改成「光的白描」：细、匀、留白多，参照马远《水图》。
- 剪影第一版是几何块拼成的纸娃娃，长发像巫师帽。后来改成弧线勾出的躯干、垂在背后的长发，再用模糊加阈值让轮廓变得有机。
- 夜里的剪影边缘光起初一圈白，像贴纸。后来改成很弱、很薄的轮廓光，主要靠身后的光衬出形体。
- 老人的手第一次没有落到孩子头上，孩子的两个发髻像熊耳朵。现在先求解手臂角度让手正好落在头顶，发型改成脑后一个发髻和一根发带。
- 宫殿着火的画面第一版每个士兵都描着霓虹般的橙边，火也是一团团圆形光球。现在剪影是纯黑的，火是一排向上舔的火舌。
- 城市里的背影第一版是僵硬的全身像，手里的杯子像手机。现在改成前景里虚焦的头与肩。
- 草原、海、书海、长卷在第一版中各推翻过若干次（见提交记录）。Canvas 纹理上传时会上下翻转，还会沿用旧快照，都已修正。
