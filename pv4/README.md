## 这一版要解决的问题

第三版「逝水」只有一条河：没有人，也没有说明，只靠水面上漂过的东西暗示。它的情绪是对的，但看完以后，观众对《万花行记》几乎一无所知。

这一版的验收标准换了：不看画面有多神秘，而看观众看完能不能说出三件事。

1. **世界经历过怎样的变化。** 亚人统治人类，人类推翻末代亚人王朝；之后亚人被药烟逼出原形、遭到追猎；明朝发展出资本主义，工业盖过了武学；再往后是废奴、美国独立战争，一直到现代。
2. **故事里有谁，他们各自是怎样的命运。**
   - 子馥幽是末代皇女，长得很慢，背负着出逃时留下的伤疤。
   - 明布川不会老，年轻时狂妄，留下了一生的悔恨；他沉睡了很久。
   - 还有一位寿命普通的老武者：他扶持人类推翻了亚人王朝，他的武学讲究守护与放手，他为两个人造了万花洲。
3. **他们还面对什么没有解决的问题。** 片尾三行字回答这一条：伤疤没有消失；他不知道怎样与一个人长久地生活；她会去哪里，还没有写下。

做法上，每个段落都要有可以讲出来的事实：一个动作（摸头、斩臂、解开镣铐、留下信），一个环境变化（宫廷 → 火 → 药烟 → 工厂烟囱 → 城市），或者一组镜头对照（同一个院子，春日两个人，雪天一个人）。文字只用来补足画面说不清的部分，比如人名、朝代和因果。粒子和光只作为环境的一部分出现，不单独承担意义。

## 设定上的约束

所有叙述都出自设定总览里已经写明的内容，没有编造重大情节。标为【未定】的地方，片子保持开放：

- **她的结局**：不写。片尾只说「她会去哪里，还没有写下」。
- **信的内容**：信纸只出现在画面里，内容不读出来。
- **海边相遇与推翻王朝的先后**：两段在片中相邻，但旁白没有用「后来」「之前」这类词。
- **伤疤的位置**：设定没有写伤在哪里，字卡只说「她身上的那道伤疤」。
- **剑灵、眷若、旻霏、「未来」组织**：这些设定还不完整，或与主线关系太远，本版不涉及。

明布川和子馥幽的名字在片中各出现一次：子馥幽在长廊一场的旁白里，明布川在周朝一场的旁白里，以及他在草原上的自我介绍「我叫明布川」。

## 画面

- **每个时代一种光**：
  - 万花洲：金色逆光。
  - 旧王朝：雾里的晨光。
  - 宫中：夜里只有灯笼。
  - 覆灭：火光。
  - 药烟一场：冷夜和灯下的光池。
  - 出逃：雨夜的蓝。
  - 周：落日麦田。
  - 夫妻两场：暖与冷对照。
  - 黄泉：黑白。
  - 她的几百年：工业的褐色和战场的灰。
  - 现代：城市夜色。
- **以远景和中景为主**：程序生成的人物不适合大特写，所以靠走位、剪影和环境光讲事情。必须看清人物的地方（摸头、跪下、举剑）都做成能读懂的整身动作。
- **镜头一直在动**：每一镜都有缓慢推拉或跟拍，人物都有动作，没有静止的人物立绘。镜头之间直接切，只在段落之间用很短的黑场淡入淡出，不用 PPT 式转场。
- **字幕都放在宽银幕黑边里**：叙述用细宋；对白用楷体，他偏冷色、她偏暖色；时代与地点用小字写在上方黑边。任何背景上都看得清。

## 声音

配乐不是从头到尾一种史诗氛围：

- **安静的生活瞬间**几乎只有环境声和一两件乐器：草原上的风和虫声、海边的浪、夫妻院子里的两把琴。
- **历史变化处**才有鼓、号和弦乐的推进：覆灭、复国、清洗，以及她的几百年。
- **关键动作前后留出寂静**：周朝两人对峙时只有风，斩下去时才是一声刀响和大鼓。
- **三个时代的招式用同一个动机**，分别换成箫、琵琶加木鱼、雨中的弦。
- **结尾直接接第三版河面的那 7.5 秒声音**，所以两版的结尾听起来是同一条河。

整体响度约 -15.7 LUFS，响度范围约 10 LU，安静段保持安静。

## 技术

从第三版沿用的部分：
- 浏览器逐帧渲染管线：无头 Chromium + WebGL2 → PNG → ffmpeg。
- 乐器合成库。
- 结尾 7.5 秒画面：裁成同一画框后拼接。

新写的部分（`src/`）：

- **人物**：用 SDF 隐式曲面拼出身体、衣服、发型、角和兽耳，经 surface nets 生成网格，再按到骨段的距离算蒙皮权重，在 GPU 上蒙皮（17 根骨骼），并烘焙环境光遮蔽。脸是在片元着色器里按静止姿态的坐标画上去的，近似泥人或陶俑的画法。
- **动作**：两段 IK。站、走、跑、跪、剑式等姿态都由少量关键帧和程序生成（`poses.js`）。亚人的兽耳和尾巴可以按「想象」淡出、淡入。
- **布料**：Verlet 网格，带结构、剪切、弯曲约束和胶囊碰撞。用于长袍下摆、宽袖、长发、尾巴、盖头和旗帜；断臂之后那只袖子会空着垂下来。
- **环境**：程序生成的草原（实例化草叶，随风摆动）、海面（Gerstner 波）、建筑、竹林、梅树；粒子系统包括雨、雪、火、烟、尘、花瓣和血。
- **渲染**：
  - 阴影贴图（PCF 软阴影）。
  - 4× MSAA，HDR。
  - 高度雾与日光散射。
  - 景深、泛光、体积光。
  - ACES 色调映射与逐镜调色。
  - 颗粒与暗角。

工具：
- `tools/cues.mjs`：把剪辑表导出给配乐脚本，音画按同一份时间表对齐。
- `tools/final.sh`：分段渲染成片，可以只重渲某一段，然后接上河面、混入配乐。
- `tools/board.py`：生成分镜总览。

## 运行

```bash
cd pv4
python3 tools/fonts.py            # 字体子集（需要原始字体目录，见脚本）
node tools/cues.mjs               # 导出剪辑表
python3 audio/score.py            # 生成配乐 assets/score.wav（需要 ../pv3/assets/score.wav 作为结尾）
tools/final.sh                    # 分段渲染 1080p，拼接河面结尾，混入配乐 → out/final/pv4.mp4
tools/release.sh                  # 压成 100 MB 以内的成片，另出预览、海报帧与分镜总览

# 调试单个镜头：
tools/stills.sh duel out/duel "a|{\"cutT\":3.4}|1.5" "b|{\"cutT\":3.4}|3.6"
# 低分辨率粗剪：
node render/render.mjs --w 640 --h 360 --workers 4 --audio none --out out/rough.mp4
```

在 4 核、无 GPU 的容器里（SwiftShader 软件渲染），1080p 平均每帧约 3.5 秒，整片约 5 小时。分段渲染出来的母带（crf 16，约 735 MB）太大，没有放进仓库；`tools/final.sh` 可以重新生成。

交付前检查过：
- 帧数：5025 帧，等于 167.5 秒 × 30 fps。
- 音画同步：周朝斩臂那一刻，画面闪白在 80.40 秒，刀声起音在 80.40 秒。
- 黑场：除片尾字卡外，没有超过 0.25 秒的黑场。
- 字幕：每一句都在黑边里，完整显示。
- 结尾：第三版河面一段的拼接处没有跳帧。

## 已知的不足

- 人物是程序生成的，脸很简单。片子刻意避开了大特写，但人群镜头里的人看上去仍然偏僵硬，比如药烟和废奴两场。
- 「以才女闻名」原本有一个夜里伏案写作的镜头，但画面不够好，最后删掉了，这条信息并进了明朝街道那一镜的旁白。
- 雨夜那一招「剑弧分开雨幕」，在画面里的效果比预想的弱。
