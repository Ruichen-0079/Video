## 为什么换成皮影

第四版的人物是用代码拼出来的三维人偶。结构和叙事都已经搭好，但人物本身很丑：脸、比例、衣服都在「像人」和「不像人」之间，近看尤其明显。用代码去逼近写实的人体，越努力越容易落进这个区间。

所以这一版不再追求写实，改用一种本来就是平面、本来就是刻出来的形式：**皮影戏**。

- **好看取决于刻工，不取决于写实。** 皮影偶本来就是侧面、平面、关节铆接的。程序画出来的平面造型在这里是正宗的样子，不是缺陷。
- **人物靠剪影来认。** 每个角色有自己的颜色、头茬和纹样：
  - 子馥幽：红衣，金钗步摇；
  - 明布川：墨蓝长袍，束发带；
  - 老武者：米白袍，白发长须；
  - 周朝的天才：白衣红边；
  - 亚人：角、兽耳和尾巴。

  远景里也一眼认得出谁是谁。
- **光还是第三版的光。** 皮影的画面来自幕后的灯：黄昏是金色，夜里是一盏灯笼，宫殿起火是红色，黄泉是黑白。第三版那种「光透过东西」的电影感，正好变成了幕后的灯透过皮子。
- **动作是真的动作。** 偶有十几个关节，靠杆子操纵，所以能走、跑、跪、举剑、劈、摸头、坐下、仰面笑。镜头在幕上推拉摇移；离幕远的皮影和布景会变虚，用来做景深。
- **形式本身也有意思。** 这个故事讲的是被史书记成一代代人的同一个人，和一段漫长、被别人讲述的历史。用一种古老的民间说书形式来讲，形式和内容是相称的。

## 没有变的部分

剪辑、旁白、配乐和第四版逐秒一致。每个镜头的起止时间相同，配乐沿用第四版的声音设计。斩臂、龙旗倒下、镣铐落地、枪响和炮声都对在原来的拍点上。

结构仍然是五个层次：

| 时间 | 段落 | 画面 |
|---|---|---|
| 0–10 | 引子 · 万花洲 | 金色草原，他走向躺在花丛里的她；他蹲下。「你很美。」「美貌也是有代价的。」 |
| 10–35 | 一 · 旧时代的世界 | 宫城前的亚人仪仗；人类奴隶弯腰抬轿；狐耳贵女边走边把耳朵和尾巴藏起来；夜里的长廊，小皇女子馥幽望着红盖头的姐姐被宫人引走；海边，老人俯身摸她的头 |
| 35–69.5 | 二 · 历史秩序的断裂 | 火把长队压向燃烧的宫城；老人在阶前替开国皇帝连挡三个亚人守卫；龙旗在火里倒下；夜巷里药烟逼出一个女人的鹿角，人群退开，士兵扑上；残部在土坡下举矛，把她推到旗下；帐中推过一袋钱；雨夜竹林出逃，她被砍伤 |
| 69.5–104.5 | 三 · 武学的传承 | 同一招式出现在三个时代：荒原的木棍，院中的师徒，雨夜里分开雨幕的剑；周朝麦田，明布川斩断天才的左臂；单臂师父和缚着左手的弟子；燃烧的道场；老武者与妻子背靠背守护（春）；他独自在雪里练剑，最后松开手（放手）；剑圣牌位的尽头站着同一个人 |
| 104.5–143 | 四 · 漫长历史中的个体命运 | 夏：她在门前一年年老去，他不变；火把下他被赶走；万花洲，「我叫明布川。」「听起来像狗的名字。」；黄泉；沉睡；明朝的烟囱街市；镣铐一个接一个落地；北美枪阵；重逢 |
| 143–167.5 | 五 · 开放的收束 | 现代公寓，夜：他惊醒，桌上留着她的信；三行字卡；接第三版的河：信沉下去，城市倒影里浮出书名 |

设定上的约束和第四版相同：只用设定总览里写明的内容。【未定】的事情一律不写：她的结局、信的内容、海边相遇与推翻王朝的先后。

## 技术

全部画面都是浏览器 2D 画布逐帧画出来的，没有使用图片素材或生成式模型。

- `src/puppet.js`：皮影偶。
  - 二维关节骨架：躯干、头、两臂各三节、两腿各两节。
  - 部件：头茬（生、旦、老生、净、童子），以及发髻、冠、盔、盖头、三角帽、角、兽耳。
  - 衣服：袍、裙、短褐、外套；裙片由腰、膝、踝的位置算凸包得到，所以站、走、跪、坐、躺都成立。
  - 宽袖按重力方向下垂；断臂之后留下空袖。
  - 每个部件都画成刻好的皮子：半透明的染色皮面、深色刻线、镂空纹样（祥云、四瓣花、回纹、鱼鳞甲、沿边的刀口小孔），再叠一层皮子的斑驳。
- `src/act.js`：表演，包括走、跑、跪、坐、剑式，以及手够到舞台上某一点的两节 IK。
- `src/set.js`：刻出来的布景，包括宫殿、长廊、灯笼、草和花、海水纹、竹、梅、松、帐篷、牌位、工厂烟囱、砖楼、路灯、公寓窗。
- `src/fx.js`：雨、雪、花瓣、火焰、火星、烟、刀光、闪白、血。全部是时间的确定函数，所以可以任意跳帧、并行渲染。
- `src/stage.js`：影窗的合成。
  1. 幕后的灯：天色渐变、灯、光晕。
  2. 纸幕的纤维。
  3. 皮影层按离幕距离从远到近，用「正片叠底」乘到幕上；离幕越远越虚、越淡，并带视差。虚的层在 1/2 或 1/4 分辨率里画和模糊，再放大。
  4. 泛光、暗角、颗粒、调色。
- 渲染：无头 Chromium，CPU 光栅（对 2D 画布来说，比软件 GPU 快约十倍），4 路并行。1080p 约 0.27 秒一帧，整片约 22 分钟。

## 运行

```bash
cd pv5
node tools/cues.mjs                 # 导出剪辑表（与第四版逐秒一致）
python3 audio/score.py              # 生成配乐 assets/score.wav（声音设计沿用第四版；需要 ../pv3/assets/score.wav 作为结尾）
tools/final.sh                      # 1080p 正片 → 接第三版河面 → 混入配乐 → out/final/pv5.mp4
tools/release.sh                    # 压成 100 MB 以内的成片，另出预览、海报帧、分镜总览

# 调试单个镜头：
tools/stills.sh duel out/duel "a|{\"cutT\":3.4}|1.5" "b|{\"cutT\":3.4}|3.6"
# 角色样张：
tools/stills.sh sheet out/sheet "a|{}|1"
```

## 已知的不足

- 人群场面（药烟一场、废奴一场）站位偏整齐，像一排排排开的皮影。这本来就是皮影戏的舞台调度，但电影感弱一些。
- 「躺」和「坐」是用整体旋转和臀部着地近似的，有几处看起来像悬在床或凳子上方一点。
- 雨夜那一招「剑弧分开雨幕」，在画面里仍然只是剑身附近一小块没有雨，效果不明显。
