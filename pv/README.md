# 《万花行记》PV · 制作说明

一支约 2 分 40 秒的程序化 PV。画面中的每一帧都由代码在浏览器里画出（Canvas 2D + WebGL），再由无头 Chromium 逐帧渲染，交给 ffmpeg 封装。配乐用 numpy 逐个采样合成，没有使用任何采样、素材、图片或 AI 生成的画面。

成片：`release/wanhua_pv_1080p.mp4`（1920×1080，30 fps）

---

## 我对这部作品的理解

设定里有一句话，我几乎把它当成了美术总纲：

> 历史事实与私人记忆，可以有各自不同的表达方式。

于是全片只用两种「物质」：

- **墨**：落在纸上，会吸收光。它用来表现被记载的历史，比如长卷、朝代印、史官的批注、考古的朱笔。
- **光**：落在夜里，只做加法。它用来表现活过的时间，比如灯、海、草原、车流。

两种画面之间的转场，也都取自原作里的意象：

- 《永乐大典》的火：夜被烧穿，露出纸。
- 墨洇开：纸上入夜。
- 光：从沉睡和重逢的那一点烧穿纸面。

人物一律不画出来，都是**线**：

- 众生是长卷上一道道短笔，写下，又很快淡去。
- 明布川是一根从夏一直不断的墨线，或一点月白的光。
- 子馥幽是一根更晚出现的石青色的线，或一点青光。她出逃负伤之后，一道朱砂细线就一直跟在她的线旁边，再没有离开。

「行记」也就有了另一层意思：长卷从一个固定的笔尖下面走过，每个生命都在那里被写下来，留下行迹。

我刻意保留了作者「整体气质」里举出的三个寻常画面：在草原上睡觉、嘲笑一个名字、在海边摸一摸谁的头。世界非常漫长，这三件事却很小。

## 结构

| 小节（75 BPM，每小节 3.2 秒） | 段落 | 内容 |
|---|---|---|
| 0–8 | 一 · 书海 | 序的前半，作者原文：「夜深了。」「乾隆巡行在无穷无尽的书架中。」「逝者如斯夫，陛下。」书架像黑色城墙，只有一盏灯，人只留下影子。最后书脊离开书架升起，火烧穿夜。 |
| 8–18 | 二 · 流 | 历史是一幅自右向左展开的长卷。夏、商、周三方朱印，旁注「皆为后世史官所加之名」。明布川生于夏；早年恋人的线并行一段后离开；周，朱砂一笔斩断天才的线，负伤流派化作一束僵直的线，随后被一团墨晕清洗，他的线变细（隐居）。末代亚人王朝覆灭时墨溅满纸；子馥幽的线出现，出逃时被朱砂划伤。 |
| 18–21 | 三 · 海 | 【画面】海边，暖光（老武者）走到一点很小的青光旁边，落下一道弧，摸了摸她的头。随后他从她身边牵出一根线，越过海面系向远处的月白：命运联系。 |
| 21–31 | 四 · 万花洲 | 光的白描画出的草原。她仰面睡着，草地上压出一片空缺；他走来，身后的草被拨开。他的名字旁有一行朱批：「听起来像狗的名字」。她说自己「忘记了想象力」，而这个以想象建成的世界偏偏在这一刻从她身边开满了花。 |
| 31–33.5 | 黄泉 | 花海边缘的黑河，两根光柱是一道门，门后有一点很暗的金色。他走去，光猛地一亮，然后暗成一点缓慢的呼吸：沉睡。（还魂成败、规则与代价都未定，所以画面不给结果。） |
| 33.5–41 | 五 · 散 | 第二幅长卷越走越快。波纹渐渐变成直线、格线，依次出现「明」印、资本、近代化、工业与海军。她的身份一个接一个写下，每一个用不同的字体：才女、废奴、美利坚·军官。许多线靠近她又离开，她的线始终只有一条。他在卷底是一行虚点，醒来后升起，与她并行（重逢）。镜头退远，近代考古用朱笔把散落的身份圈起来连成一条线：「注：以上诸人，或为同一人。」 |
| 41–48 + 尾声 | 六 · 城 | 序的后半。高楼窗外的车流是长曝光的光迹。两道光并行一段，青色那道沿路走远了，没有熄灭。屋里有书桌、她留下的信纸和一杯热水。作者原文：「我看见时间尾随其后，从街的这边驶来，那一边逝去。」「真是他妈的，逝者如斯夫。」最后是书名。 |

首尾是同一句话的两种说法：开头是梦里学士对乾隆说的「逝者如斯夫，陛下」，结尾是明布川自己骂出来的「真是他妈的，逝者如斯夫」。

## 尊重原作的几条自我约束

- 画面里出现的引号文字只用两类：作者原文（序、「忘记了想象力」、「最像人的亚人／最像亚人的人类」），以及设定中已经确定的事实。没有替人物编台词。
- 标为【未定】的内容都留成开放的，包括黄泉还魂的结果、明布川长生的来源、清朝在架空史中的位置。**子馥幽的结局尤其如此**：她的线最后只是走出画面，没有被画成熄灭。
- 海边相遇是【画面】，前因后果未定，所以只呈现动作，并用作者自己的句子做字幕。
- 「美利坚」「近代考古」「废奴」等都来自设定原文。考古批注里的「或为」是刻意的：世界内部的学者有自己的局限。
- 「听起来像狗的名字」这条朱批，是对设定中「她嘲笑『明布川』听起来像狗的名字」的转述，写成批注而不是对白。
- 人物外貌不画，所以也没有替两位剑灵（眷若、旻霏）凭空设计形象。

**关于书名**：设定总览写的是《万花行记》，片中按它使用。如果正式书名是《万花行迹》，改 `src/config.js` 里的一行，再运行一次 `tools/build_assets.py` 和渲染即可。

## 研究参考作品时学到、并刻意没有照搬的东西

参考 MV（world.execute(me) 同人，Claude Code 制作）真正值得学的，不是那些镜头，而是这几件事：

1. 给整部作品找到一种「原生材料」。它的材料是聊天界面，所有画面都由输入框、开关、代码长出来；这里的材料是墨与光、纸与夜。
2. 色彩少而有叙事。它从炭灰加一种橙色，到危机时转为红；这里只用墨、朱砂、石青、月白、灯金和花海那一段的柔色。
3. 文字本身就是主角。这里的字大多不是「显示」出来的，而是按笔顺被「写」出来的。
4. 结构首尾相扣。
5. 确定性的 `renderFrame(t)` 加无头浏览器逐帧渲染，并且反复抽帧检查。

刻意不做的：不用二次元立绘，不做 UI 隐喻，不做高密度的歌词卡点。这部小说的节奏是慢而密的，画面也就慢一些。

## 技术

```
pv/
  index.html            渲染页面
  src/main.js           window.PV.renderFrame(t)：给定时间，确定地画出一帧
  src/gl.js             WebGL2 合成器（HDR 光缓冲、墨吸收缓冲、纸/夜背景、焚/洇/光转场、bloom、ACES、颗粒）
  src/camera.js         透视相机与景深（线条按弥散圆变粗变淡）
  src/draw.js           三维折线、毛笔线（压力、收锋、飞白）、墨晕、调色板
  src/text.js           Canvas 字体排版；按笔顺书写（Make Me a Hanzi 笔画中线）
  src/fx.js             光写字、墨写字、印章
  src/timeline.js       节拍表（与音乐共用 assets/cues.json）和全片调色
  src/scenes/*.js       六个段落
  audio/score.py        配乐合成：琴（加法合成拨弦，带吟猱滑音）、弹拨、箫、弦乐铺底、编钟、大鼓、锣、海浪、城市嗡鸣、FFT 卷积混响
  render/render.mjs     并行逐帧渲染 → ffmpeg
  tools/build_assets.py 从源码收集用到的汉字，生成字体子集与笔画数据
  tools/sheet.py        联系表（抽帧检查用）
```

几个要点：

- **两层画布加两个浮点缓冲**：光（加色）和墨（吸收，按 `exp(-吸收率)` 作用在纸上）分开累积。同一套线条代码因此既能在夜里发光，也能在纸上落墨，两种世界的视觉才统一。
- **墨的颜色是吸收率**：石青吸收红光，朱砂吸收绿光和蓝光，墨吸收全部。纸的纤维会让墨色不匀。
- **一切都是时间的函数**，没有逐帧累积的状态，所以可以把时间轴切成几段并行渲染。长卷上「已写下的部分」由卷上位置和笔尖位置算出；草被人拨开后慢慢立起，是对他过去几秒位置的采样。
- **画面与音乐共用节拍表**。所有关键动作都按「第几小节第几拍」来写，比如斩在第 12 小节第 3 拍，万花在第 25 小节，重逢在第 39 小节。
- **颗粒加在伽马之后**。之前加在线性空间里，暗部被放大成噪点，视频码率一度高达 100 Mbps。改到显示空间后，噪点降下来，码率约 5 Mbps。

## 运行

```bash
cd pv
npm install                               # 只需要 playwright-core
python3 audio/score.py                    # → assets/score.wav（约 25 秒）
node render/render.mjs --stills 30,84,150 --w 960 --h 540      # 抽帧检查
node render/render.mjs --w 640 --h 360 --out out/preview.mp4   # 快速预览（4 核约 10 分钟）
node render/render.mjs --w 1920 --h 1080 --crf 18 --out out/pv.mp4  # 成片（4 核约 80 分钟）
```

需要 Chromium（`CHROME` 环境变量可指定路径）、ffmpeg、Python 3 + numpy + scipy。字体子集与笔画数据已经提交在 `assets/` 中；只有改动了画面中的文字，才需要重新运行 `tools/build_assets.py`（原始字体的下载地址写在脚本开头）。

## 制作过程中推翻过的东西

- 最初的风格测试是粗而亮的发光线，像屏保。改成「光的白描」：细、匀、留白多，参照马远《水图》。
- 书海最初光照太均匀，整面书架都是亮的。后来改成只有灯附近才画出书脊，其余交给黑暗。
- 书脊离开书架时，最初是冲向镜头，像科幻片里的跃迁。改成像烟一样向上升起。
- 海最初被压成地平线上的一条细带，人物的光也悬在天上。后来抬高机位俯看岸边，让海占满画面中部。
- 草原第一次渲染根本没有草（显隐的前沿写反了）；第二次花开得过曝，整片白；第三次草直上直下像在下雨，最后加大弯曲、调低密度和景深。
- 黄泉的门第一版不小心画成了日式鸟居，改成两根光柱。
- 长卷第一版的笔画太细太淡，几乎看不见众生，河道也太窄。
- Canvas 纹理上传时上下翻转，所有字都是倒着的；仅调用 clearRect 时，Chromium 会沿用旧快照，导致别的段落的字「串场」。两处都已修正。
